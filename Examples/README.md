# Examples

Run an example script from its own folder; do not run `AtomSpect.py` directly.

| Name | Features shown |
|---|---|
| `Ar_ex1` | Rough (but quick) ability to add two spectra on the same plot. |
| `CIII_ex1` | `MultiSpec`, `ion_vel`, `GaussianInstrum`, using them to match the temperature. Different ways to plot. |
| `He_ex1` | Polarization filter matching and accurate B-field values. Shows that low resolution allows a curve similar to the spectrometer. Shows non-dipole-like transitions. |
| `Rb_ex1` | Demonstrates the ability to include hyperfine structure. |
| `SpectrometerPredict` | Primary workhorse example which generates slider plots. Great for predicting whether spectral features can be resolved for a given temperature, magnetic field, and/or spectrometer resolution. |
